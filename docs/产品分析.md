# 百工·坊（Fang）产品分析

> 集群内创作工具的共享外壳（基础设施）· 2026-10-19 留档

## 要做什么

**核心职能**：为六个创作工具（墨/剪/陶/乐/筑/锻）提供统一的桌面应用外壳与 UI 基础设施，一次成型、处处复用。

**范围**：

- 停靠面板系统（面板坞、停靠/折叠/重组、工作区布局的保存与切换）
- 快捷键/命令框架（键位映射、命令面板）
- 主题与设计 token（深色主题为默认）
- 菜单栏与上下文选项栏
- 通用控件（滑杆、取色器、树、表格、拖拽式数值输入等）
- Tauri 窗口/IPC 约定（可选层）

**明确不做**：各工具的业务功能（图层、时间线、3D 视口等）不属于外壳。

**分发方式**：npm 私有包，semver 版本化，各工具按版本锁定、独立升级。

## 开发原则

- **API 需求驱动**：不预先设计接口，从第一个真实工具的开发中沉淀，避免过早抽象；
- 「纸」为文档消费型工具，不使用此外壳，界面范式独立。

## 页面呈现样式

坊本身无最终用户界面；其「呈现」体现为各创作工具的统一外观——深色主题、可停靠面板坞、密集快捷键、上下文选项栏。开发期内置 Storybook 式 demo 页面（自写极简 demo，非 Storybook 工具链，定夺见[工程骨架决策](工程骨架决策.md)第 1 轮），用于展示与测试组件。
